# 🎬 FlickApp

FlickApp is a modern Flutter application for discovering movies, viewing detailed information, searching films, and managing favorite movies. The app provides a clean UI, fast performance, and integration with external movie APIs.

## ✨ Features

* 🔥 Browse popular movies
* 🔍 Search movies by title
* ❤️ Add and remove favorites
* 📄 View detailed movie information
* 🎥 Movie posters and ratings
* 🌙 Modern Material Design interface
* ☁️ Firebase Authentication
* 💾 Local data storage
* 🌐 REST API integration

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/yourusername/FlickApp.git
```

### Open the project

```bash
cd FlickApp
```

### Install dependencies

```bash
flutter pub get
```

### Run the application

```bash
flutter run
```
